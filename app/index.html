Download a backup

Every deck, flashcard, study guide and your progress, in one file. Keep it somewhere safe, such as OneDrive or a USB stick.

Restore from a backup

Merge a backup file back in. Decks and concepts are only added, never removed. Older Drill backups work too.

Automatic snapshots

—

MonoSpace copies its whole database into the backups folder each time it starts and once a day.

To go back to a snapshot, close MonoSpace and run python -m server.restore <name> in the MonoSpace folder; it shows what will change and asks you to type yes.

Connect a different AI

MonoSpace can use, online: Claude Code, OpenAI Codex, Google Gemini CLI, or any other command-line AI — each with your own sign-in, no API keys. On this PC: any Ollama model (Qwen, Llama, Gemma, Mistral…), or LM Studio, llama.cpp, Jan or vLLM. Add two or three lines to your settings file, save it, then press Reload AI settings. Examples:

ONLINE_AI=codex              # or claude, gemini, custom, off
LOCAL_AI=ollama              # or openai (LM Studio, llama.cpp, Jan, vLLM), off
OLLAMA_MODEL=llama3.1:8b     # any model you pulled with: ollama pull …

Step-by-step instructions for each AI: docs/CONNECT-AI.md in the MonoSpace project (also on GitHub).
